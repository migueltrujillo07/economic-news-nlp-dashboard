# Economic News NLP Dashboard

This project analyzes economic news articles using Natural Language Processing (NLP) techniques to extract sentiment, topics, and trends from global economic coverage.

## Project Goals
- Analyze sentiment in economic news over time
- Identify dominant macroeconomic topics (e.g. inflation, interest rates, growth)
- Extract key entities such as countries and central banks
- Visualize insights through an interactive dashboard

## Tech Stack
- Python, Pandas
- NLP: Transformers, BERTopic, spaCy
- Visualization: Matplotlib, Plotly, Streamlit
